# Customer Churn & Retention Analytics

An end-to-end data analytics project analyzing customer churn behavior in the telecom sector using **Python, SQL (SQLite), and Power BI**.

## Project Workflow
1. **Data Cleaning & Preprocessing (Python):** Handled missing and inconsistent values in `TotalCharges` and exported a clean dataset along with an SQLite database.
2. **Exploratory Business Analysis (SQL):** Queried customer segments, overall churn rate, revenue loss, and high-risk accounts.
3. **Data Visualization (Power BI):** Built an interactive dashboard highlighting contract-level churn patterns and key KPIs.

## Key Business Insights
- **Contract Type Impact:** Customers on **Month-to-Month contracts** show the highest churn rate compared to one-year and two-year contracts.
- **Retention Focus:** Converting high-monthly-charge, month-to-month subscribers into annual plans presents the biggest opportunity to reduce revenue loss.

## Tools Used
- **Python (Pandas, SQLite3)**
- **SQL (DB Browser for SQLite)**
- **Microsoft Power BI**
